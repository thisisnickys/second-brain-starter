# How a second brain actually works

This is a real note. Delete it once you have your own — but read it first,
because it explains the one idea the whole system rests on.

## Core ideas

- **The markdown files are the truth.** Everything else — the search index, the
  graph, the galaxy visualization — is a *cache* built from these files. If every
  index burned down, one command rebuilds them. If the files burn down, it is gone.
- **Frontmatter is not decoration.** The block between the `---` lines is what
  makes a note findable, colorable, and countable. A note that fails the linter
  never lands, on purpose.
- **Capture is worthless without an Apply line.** A note that says "interesting"
  is a bookmark. A note that says what you will *do differently* is a second brain.
- **Retrieval beats storage.** Saving is easy and feels productive. The system is
  only real when you can ask it a question months later and get your own answer back.

## Apply

Write your next note about something you actually decided this week, not
something you read. Decisions are the notes you will search for later.
